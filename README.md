`three-mmd-viewer-live` 一个以单个 Python 文件部署的 MMD 局域网页面查看器。它能够直接加载 PMX/PMD 模型及其贴图，在现代浏览器中完成模型浏览、灯光调整、骨骼姿势编辑、IK 控制、VMD 动作播放、表情控制、按需物理模拟、HDR 与后期处理，以及高清截图和转台视频导出。

项目不需要安装 Node.js、npm、Web 框架或 Python 第三方包。服务端、HTML、CSS 和 JavaScript 均包含在 [`main.py`](main.py) 中，模型文件仍保留在用户自己的目录里。

## 功能概览

### 模型与材质

- 直接读取 PMX 和 PMD 模型。
- 加载 PNG、JPEG、BMP、TGA、SPA 和 SPH 等常见 MMD 贴图资源。
- 使用 Three.js 的 MMD Toon Shader 近似表现 MMD 卡通材质、Sphere Map 和 Toon 阴影。
- 自动处理 Linux 下贴图路径大小写不一致的问题。例如，模型中记录的 `hair.png` 可以匹配磁盘上的 `Hair.png`。
- 支持模型阴影、地面阴影、参考网格、线框模式和抗锯齿轮廓。

### 镜头与灯光

- 鼠标旋转、缩放和平移镜头。
- 调整焦段、传感器尺寸、水平角、俯仰角、相机距离和注视高度。
- 调整主光亮度、颜色、水平角、高度角和阴影柔度。
- 调整环境光、补光、曝光和背景颜色。
- 按需载入 HDR 摄影棚环境。
- 可选泛光与景深效果，默认关闭以控制性能消耗。

### 骨骼与姿势编辑

- 直接点击模型表面，根据蒙皮权重选择主要骨骼。
- 通过三轴操纵器移动或旋转模型整体及单根骨骼。
- 支持本地坐标和世界坐标。
- 提供 XYZ 旋转、位置滑杆，用于精确调整。
- 对常见日文 MMD 骨骼名称进行中文别名显示和分类。
- 按躯干、头部、手臂、腿部、物理骨骼等类别筛选。
- 收藏常用骨骼。
- 在视口中高亮当前骨骼，并显示骨骼名称。
- 可显示完整骨架辅助线。
- 提供基础关节角度限制，减少极端反折。

### IK 与镜像

- 根据模型骨架自动发现左手、右手、左脚、右脚、头部和腰部控制链。
- 使用可拖动 IK 控制柄调整关键部位。
- 支持调节 IK 求解迭代次数。
- 支持将当前骨骼姿势镜像到另一侧。
- 支持交换左右姿势。
- 支持实时对称编辑。

IK 控制柄依赖模型采用较常见的 MMD 骨骼命名和层级。非标准骨架可能只显示部分控制柄，此时仍可通过骨骼列表和普通操纵器完成编辑。

### 历史与姿势保存

- 支持姿势撤销和重做。
- 连续拖动操纵器或滑杆只记录为一个历史步骤。
- 支持导出和导入 JSON 姿势文件。
- 提供四个浏览器本地姿势槽位。
- 姿势槽位保存在浏览器 `localStorage` 中，不会写入服务端。
- 支持单骨复位和全身复位。

### VMD 动作

- 从浏览器本地选择 VMD 文件。
- 提供播放、暂停、停止和移除操作。
- 提供时间轴定位、播放速度和循环控制。
- 用户手工姿势作为覆盖层叠加在 VMD 动作之上。
- 拖动骨骼操纵器时会暂停动作，避免正在播放的动画干扰编辑。

VMD 文件通过浏览器的本地文件接口读取，不会被上传到 Python 服务端或写入模型目录。

### 表情与视线

- 自动列出模型中的全部 Morph，并支持名称筛选和权重调整。
- 提供微笑、闭眼、惊讶、难过、左右眨眼等快捷预设。
- 支持眼睛跟随相机。
- 支持自动眨眼。
- 可随姿势一起保存和恢复 Morph 权重。

快捷表情通过常见 Morph 名称进行匹配。若模型采用完全不同的命名方式，仍可在完整 Morph 列表中手动调整。

### 物理模拟

- 使用 Ammo.js 驱动 PMX 中的刚体和关节。
- 可模拟头发、裙摆、领带和其他物理部件。
- 支持调整重力强度和模拟质量。
- 支持重置物理状态。

物理模拟**默认关闭**。初次进入页面时不会下载 Ammo.js、不会初始化物理世界，也不会执行物理计算。只有用户主动打开“启用 Ammo 物理”后，服务端才会请求 Ammo JavaScript 与 WASM 文件并在浏览器中初始化。配置较低的设备可以一直保持关闭。

### 截图与视频

- 导出当前视口、1080p、2K 或 4K PNG 截图。
- 支持透明截图背景。
- 录制完整一周旋转的 WebM 转台视频。
- 可设置转台视频时长。

WebM 录制依赖浏览器的 `MediaRecorder` 和 `canvas.captureStream()`。Chromium、Chrome 和 Edge 的支持通常较好；部分 Safari 版本可能不支持或只能使用不同的视频编码。

## 环境要求

- Python 3.10 或更高版本。
- 支持 WebGL 的现代浏览器，推荐使用较新的 Chrome、Chromium、Edge 或 Firefox。
- 一套目录结构完整的 PMX/PMD 模型资源。
- 首次加载页面时，服务端需要能够访问 jsDelivr，以获取固定版本的前端依赖。
- 只有启用 HDR 或物理时，才会额外请求对应的 HDR、Ammo JS 和 Ammo WASM 资源。

Python 端只使用标准库，不需要执行 `pip install`。

## 获取项目

```bash
git clone https://github.com/ra1nyxin/three-mmd-viewer-live.git
cd three-mmd-viewer-live
```

也可以直接下载仓库中的 `main.py`，脚本本身即可运行。

## 准备模型目录

推荐保持模型作者提供的原始目录层级。例如：

```text
/data/miku-model/
├── model.pmx
├── tex/
│   ├── body.png
│   ├── face.png
│   └── hair.png
├── toon/
│   └── toon-01.bmp
└── spa/
    └── shine.spa
```

不要只复制 PMX 文件而遗漏贴图目录。PMX 中记录的是相对贴图路径，目录层级改变后可能无法找到资源。

如果目录中有多个 PMX/PMD 文件，可以通过 `--model` 明确选择其中一个。未指定时，脚本优先选择当前模型目录中按名称排序后的第一个 PMX 文件，其次选择 PMD 文件。

## 启动方式

### 指定模型目录

这是最明确的启动方式：

```bash
python3 main.py --model-dir /data/miku-model
```

指定模型文件：

```bash
python3 main.py \
  --model-dir /data/miku-model \
  --model "model.pmx"
```

### 从模型目录启动

`--model-dir` 的默认值是启动命令所在的当前目录。因此也可以进入模型目录后运行脚本：

```bash
cd /data/miku-model
python3 /path/to/three-mmd-viewer-live/main.py
```

### 只允许本机访问

默认监听 `0.0.0.0`，局域网中的其他设备可以访问。如果只希望当前电脑访问：

```bash
python3 main.py \
  --host 127.0.0.1 \
  --model-dir /data/miku-model
```

### 修改端口

默认端口为 `51943`：

```bash
python3 main.py \
  --port 8080 \
  --model-dir /data/miku-model
```

启动成功后终端会显示类似内容：

```text
MMD model : /data/miku-model/model.pmx
Local URL : http://127.0.0.1:51943/
LAN URL   : http://192.168.1.20:51943/
Press Ctrl+C to stop.
```

在本机浏览器打开 `Local URL`，或在同一局域网的手机、平板和其他电脑上打开 `LAN URL`。

按 `Ctrl+C` 停止服务。

## 命令行参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--host` | `0.0.0.0` | HTTP 服务监听地址 |
| `--port` | `51943` | HTTP 服务监听端口 |
| `--model-dir` | 当前工作目录 | PMX/PMD 与贴图所在目录 |
| `--model` | 自动选择 | `--model-dir` 内的模型文件名 |
| `-h`, `--help` | - | 显示帮助信息 |

查看完整参数：

```bash
python3 main.py --help
```

## 页面操作

### 基础视口操作

- 鼠标左键拖动：旋转镜头。
- 鼠标滚轮：缩放。
- 鼠标右键拖动：平移镜头。
- 点击模型表面：选择该位置权重最大的骨骼。
- 拖动彩色 XYZ 操纵器：移动或旋转当前对象。

触摸屏设备可使用单指和双指完成对应的镜头操作。移动端右上角按钮用于打开参数面板。

### 键盘快捷键

| 快捷键 | 功能 |
| --- | --- |
| `R` | 切换到旋转操纵器 |
| `T` | 切换到移动操纵器 |
| `Ctrl+Z` / `Command+Z` | 撤销姿势操作 |
| `Ctrl+Y` | 重做姿势操作 |
| `Ctrl+Shift+Z` / `Command+Shift+Z` | 重做姿势操作 |

当焦点位于输入框、滑杆或下拉框时，快捷键不会抢占输入。

### 推荐摆姿势流程

1. 在“动作”面板选择骨骼分类，或直接点击人物对应部位。
2. 先使用旋转操纵器调整肩膀、手臂、腰部和腿部的大方向。
3. 使用 IK 控制柄调整手、脚、头部或重心位置。
4. 使用 XYZ 滑杆精调单根骨骼。
5. 需要对称动作时启用实时对称，或使用镜像复制。
6. 通过“显示骨架”检查骨骼层级和关节状态。
7. 使用姿势槽位或导出 JSON 保存结果。

若控制柄或骨骼出现不自然的反折，可提高 IK 求解次数、启用关节角度限制，或切回单骨旋转进行修正。

## 网络与代理

Three.js、Lucide、Ammo 和 HDR 资源由 Python 服务端代为请求，并在服务进程内存中缓存。局域网客户端只需要连接这台 Python 服务所在的电脑，不需要每台设备分别下载依赖。

若服务器访问海外 CDN 较慢，可以在启动前配置标准代理环境变量：

```bash
export HTTPS_PROXY=http://127.0.0.1:7890
export HTTP_PROXY=http://127.0.0.1:7890
python3 main.py --model-dir /data/miku-model
```

请将代理地址替换为实际可用的 HTTP 代理。服务重启后，内存中的前端资源缓存会重新建立。

## 性能建议

### 低配置电脑或移动设备

- 保持物理模拟关闭。
- 保持 HDR、泛光和景深关闭。
- 不要同时打开骨架、参考网格和线框模式。
- 降低浏览器窗口尺寸或设备显示缩放。
- 避免使用大量 4K/8K 未压缩贴图的模型。
- 截图时再临时选择 2K 或 4K，完成后页面会恢复当前视口尺寸。

### 物理模拟

- 从模拟质量 `1` 或 `2` 开始。
- 若帧率明显下降，先降低模拟质量，再考虑减小重力。
- 修改姿势后头发或裙摆出现异常时，点击“重置物理状态”。
- 首次启用物理会有一次下载和初始化等待，这是正常现象。

### 后期效果

泛光和景深会启用额外的离屏渲染流程，并暂时不使用 MMD 轮廓渲染路径。移动设备上建议只启用一种效果，并控制较低强度。

## 安全说明

- 服务默认监听所有网络接口，但没有账户、密码、权限管理或 HTTPS。
- 它适合可信局域网，不应直接暴露到公网。
- 如果只需本机使用，请添加 `--host 127.0.0.1`。
- 服务端不会提供任意目录列表，只允许读取模型目录内经过白名单限制的模型和贴图后缀。
- 路径解析会阻止 `..` 等目录穿越请求。
- 浏览器选择的 VMD 和姿势 JSON 不会自动上传到服务端。
- 其他访问者能够通过浏览器网络请求取得当前查看所必需的模型与贴图，因此即使在局域网内，也应遵守模型作者的再分发规定。

## 格式支持与限制

### 支持

- 模型：PMX、PMD。
- 贴图：PNG、JPG/JPEG、BMP、TGA、SPA、SPH。
- 动作：浏览器本地 VMD。
- 姿势：项目自定义 JSON 姿势文件。
- 导出：PNG、WebM。

### 当前限制

- 不支持直接读取 3ds Max 的 `.max` 文件。
- 不支持直接读取 FBX、OBJ、VRM 或 glTF 模型。
- MMD 的 `.fx`、`.fxsub` 和特定 MME Shader 不会在浏览器中原样执行。
- 材质效果是基于 MMD Toon Shader、Sphere Map、灯光与 WebGL 后期处理的近似还原。
- IK 自动发现依赖常见骨骼命名，非标准模型可能需要手动选择骨骼。
- 快捷表情依赖常见 Morph 名称，未匹配时需要手工调整 Morph。
- WebM 视频导出依赖浏览器能力，编码和兼容性由浏览器决定。
- Python 服务本身不负责模型格式转换。

## 常见问题

### 启动时提示找不到 PMX/PMD

确认 `--model-dir` 指向模型文件所在目录，而不是贴图子目录：

```bash
find /data/miku-model -maxdepth 1 -type f \( -iname '*.pmx' -o -iname '*.pmd' \)
```

如果模型位于更深层目录，请将 `--model-dir` 指向实际包含模型文件的那一级。

### 页面可以打开，但模型一直加载失败

检查启动终端中的请求日志：

- `/api/config` 失败通常表示服务端模型配置有问题。
- PMX 请求失败通常表示模型被移动或权限不足。
- `/vendor/` 请求返回 `502` 通常表示服务器无法访问外部 CDN。
- 贴图返回 `404` 通常表示模型记录的相对路径与实际目录不一致。

### 模型没有贴图或部分材质发白

- 确认贴图目录与 PMX 文件的相对位置没有改变。
- 检查文件是否确实存在，而不是只存在于 ZIP 压缩包中。
- 文件名大小写差异会自动回退匹配，但完全不同的文件名无法自动判断。
- 模型依赖的 MME `.fx` 效果不会原样运行，需要使用页面灯光和后期参数近似调整。

### 其他设备无法访问

- 确认访问的是终端显示的 `LAN URL`，不是 `127.0.0.1`。
- 确认两台设备位于同一局域网，且客户端隔离功能没有开启。
- 检查服务器防火墙是否允许当前 TCP 端口。
- 检查启动参数是否误用了 `--host 127.0.0.1`。
- 尝试在服务器本机访问 `http://127.0.0.1:51943/healthz`，正常应返回 `ok`。

### 端口已被占用

改用其他端口：

```bash
python3 main.py --port 51944 --model-dir /data/miku-model
```

### 开启物理后明显卡顿

先关闭物理或将模拟质量调到 `1`。Ammo 物理主要运行在 CPU 上，复杂刚体模型在移动设备和低功耗处理器上可能造成明显负载。

### HDR 无法载入

HDR 是按需从外部 CDN 获取的。确认 Python 服务所在电脑能够访问 jsDelivr，必要时配置 `HTTPS_PROXY`。HDR 失败不会影响基础灯光和模型查看。

### 视频按钮提示浏览器不支持

换用较新的 Chrome、Chromium 或 Edge。部分浏览器缺少 `canvas.captureStream()`、`MediaRecorder` 或 WebM 编码支持，但 PNG 截图仍可正常使用。

## HTTP 端点

项目不是通用文件服务器，只暴露查看器运行所需的有限端点：

| 路径 | 用途 |
| --- | --- |
| `/` | 内嵌的查看器页面 |
| `/api/config` | 当前模型名称、大小和模型 URL |
| `/model/...` | 白名单限制下的模型与贴图资源 |
| `/vendor/...` | 固定版本前端依赖代理与内存缓存 |
| `/healthz` | 服务健康检查，正常返回 `ok` |

## 技术实现

- Python `ThreadingHTTPServer` 提供多线程静态资源服务。
- HTML、CSS 和 JavaScript 直接嵌入 `main.py`。
- Three.js 固定为 `0.170.0`，这是仍包含官方 MMDLoader、MMDAnimationHelper、MMDPhysics 与相关解析器的版本。
- `MMDLoader` 负责 PMX/PMD、贴图和 VMD 解析。
- `OrbitControls` 负责镜头交互。
- `TransformControls` 负责骨骼与整体变换操纵器。
- `CCDIKSolver` 负责 MMD 原生 IK 和关键控制链。
- `MMDAnimationHelper` 组合 VMD、MMD IK、Grant 与可选物理。
- Ammo.js WASM 负责刚体与关节模拟。
- `EffectComposer`、`UnrealBloomPass` 和 `BokehPass` 负责可选后期效果。
- `RGBELoader` 负责 HDR 环境加载。
- 姿势状态、历史记录、镜像和动画覆盖层由页面端管理。

## 开发与检查

项目没有构建步骤。修改 `main.py` 后可以先运行 Python 编译检查：

```bash
python3 -m py_compile main.py
```

随后准备一个有权使用的测试模型，并启动服务：

```bash
python3 main.py --host 127.0.0.1 --model-dir /data/test-model
```

建议至少检查以下流程：

1. 模型、Toon 和 Sphere Map 贴图正常加载。
2. 鼠标和触摸镜头操作正常。
3. 点击表面可选择骨骼，操纵器能够移动和旋转。
4. 撤销、重做、镜像、姿势槽位和 JSON 导入导出正常。
5. VMD 可以播放、暂停和拖动时间轴。
6. 物理保持默认关闭，并能在手动开启后正常初始化。
7. HDR、泛光和景深开关可以独立工作。
8. 普通、透明和高分辨率截图正常。
9. 桌面与移动尺寸下参数面板不遮挡主要操作。
